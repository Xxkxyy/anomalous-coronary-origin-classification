# Anomalous Coronary Origin Classification

Deep-learning classification of anomalous coronary artery origins from CT images.

## Overview

This repository provides an end-to-end pipeline for classifying anomalous
origins of the coronary arteries using 2.5D / 3D CNNs pretrained on
ImageNet / Kinetics-400:

```
DICOM -> Step 1: Preprocess -> Step 2: Split -> Step 3: Train -> Step 4: Evaluate -> Step 5: Explainability
```

Key features:
- Multi-slice 2.5D and 3D models (ResNet-50, DenseNet-121, 3D ResNet-18, ViT-B/16)
- 5-fold stratified cross-validation
- SCI-grade evaluation: ROC curves, confusion matrices, calibration, DeLong test
- Grad-CAM / saliency map explainability
- External validation with ensemble inference

## Installation

```bash
conda create -n coroanomaly python=3.9
conda activate coroanomaly
pip install -r requirements.txt
```

Requires Python 3.9+ and PyTorch 2.0+. GPU is recommended.

## Quick start: inference with pretrained checkpoints

Place your 5-fold checkpoints under `checkpoints/<model>/fold_{0..4}/best_model.pth`,
then run:

```bash
# Single patient DICOM directory
python predict.py -i ./case_dicom/ -o results.csv

# Batch patients (each subdirectory is a patient)
python predict.py -i ./all_cases/ -o results.csv

# Multi-model ensemble + test-time augmentation
python predict.py -i ./cases/ --ensemble --tta -o results.csv
```

Inputs can be DICOM series or preprocessed NIfTI files.

## Training from scratch

```bash
# Preprocess + split + train + evaluate (default: ResNet-50)
python run_pipeline.py

# Train a specific model
python run_pipeline.py --model densenet121
```

The data directory is expected to follow the layout used by
`scripts/step1_preprocess.py` (DICOM series grouped by patient). See the
docstring in each script for details.

## Repository layout

```
├── predict.py                 # Inference entry point
├── run_pipeline.py            # Training pipeline entry point
├── requirements.txt
├── scripts/
│   ├── step1_preprocess.py    # DICOM -> NIfTI -> crop -> normalize
│   ├── step2_split.py         # 8:2 holdout + 5-fold CV split
│   ├── step3_train.py         # 5-fold CV training
│   ├── step4_evaluate.py      # Evaluation metrics & figures
│   ├── step5_explain.py       # Grad-CAM / saliency explainability
│   └── external_validation.py # External cohort validation
└── sample_data/               # Synthetic example data (see below)
```

## Synthetic example data

`sample_data/` contains synthetic NIfTI volumes generated by
`tools/make_synthetic_data.py` for a quick smoke test:

```bash
python tools/make_synthetic_data.py
python predict.py -i sample_data/ -o sample_results.csv
```

## Data

Raw DICOM data are not included for patient privacy. To reproduce the
